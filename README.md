# DIY-NI-MASCHINE-MIKRO.public

Public-facing content for the DIY-NI-MASCHINE-MIKRO project -- bringing a Native
Instruments Maschine Mikro MK3 online as a plain, class-compliant MIDI controller, without
any NI software.

- [`documentation-github-page/`](documentation-github-page) -- the Hugo (Stack theme)
  build-log site, deployed to GitHub Pages by `.github/workflows/hugo.yml`.

Source code, the detailed protocol reference and the test recordings live in a separate,
private repository for now.

See: https://jens-goes-mad.github.io/DIY-NI-MASCHINE-MIKRO.public/overview/
